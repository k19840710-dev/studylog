# StudyLog

勉強時間を記録・可視化するWebアプリです。

公開URL: https://k19840710-dev.github.io/studylog/

## 主な機能

- 通常タイマー / ポモドーロタイマー (集中・休憩の時間を設定可能、終了時に通知)
- 手動での記録・記録の編集・削除 (元に戻す付き)
- 科目の追加・名前と色の変更・削除
- 直近7日間の科目別グラフ、月間ヒートマップカレンダー、科目別バランス
- 1日の目標、連続学習日数
- データの書き出し / 読み込み (JSON でバックアップ)
- ダークモード、キーボードショートカット、ホーム画面に追加 (PWA・オフライン対応)

- 端末間の同期 (Firebase Realtime Database + 匿名認証。ログイン不要)

データは端末 (localStorage) と Firebase の両方に保存され、アプリを開いている端末どうしで自動的に同期されます。
同期データは URL を知っている人なら読み書きできるため、ときどき「データを書き出す」でバックアップを取ってください。
